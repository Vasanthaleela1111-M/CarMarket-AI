# 🚗 CarMarket-AI

### AI-Powered Used Car Resale Prediction & Recommendation Platform

CarMarket-AI is an intelligent machine learning platform designed to help users estimate the resale price of used cars and discover suitable vehicles based on their preferences.

The platform combines machine learning-based price prediction, hybrid recommendation techniques, and an interactive AI chatbot to provide a more personalized car-buying experience.

---

## 🚀 Features

* Used car resale price prediction
* Machine learning-based price estimation
* Personalized car recommendations
* Preference-based recommendation matching
* Cosine similarity for car similarity analysis
* K-Means clustering for recommendation grouping
* Interactive AI car chatbot
* Budget-based car search
* Brand, fuel type, body type, transmission, and city-based filtering
* Interactive Streamlit interface

---

## 🏗️ System Workflow

1. Load and preprocess used car data
2. Clean and transform vehicle features
3. Train the resale price prediction model
4. Generate recommendation features
5. Calculate car similarity and preference matching
6. Apply clustering for recommendation grouping
7. Accept user requirements through the chatbot
8. Predict resale price or recommend suitable cars
9. Display results through the Streamlit application

---

## 🧠 Machine Learning

### Price Prediction

The resale price prediction component uses a machine learning model trained on used-car attributes to estimate the expected resale value of a vehicle.

### Recommendation Engine

The recommendation system combines multiple approaches:

* Preference-based matching
* Cosine similarity
* K-Means clustering

This hybrid approach helps identify cars that are relevant to the user's requirements rather than relying on a single recommendation technique.

---

## 💬 AI Car Chatbot

The integrated chatbot allows users to interact with the application using natural language.

Users can provide requirements such as:

* Budget
* Brand
* Fuel type
* Body type
* Transmission
* City

The chatbot interprets these preferences and provides relevant vehicle recommendations.

The goal of CarMarket-AI is to make used-car selection easier by combining **price prediction, personalized recommendations, and conversational interaction** into a single intelligent platform.
